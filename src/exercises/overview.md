# Exercise Overview

**Learning goal:** Understand how to use practice exercises

---

## Exercise types

### 1. Module drills
Practice specific skills after each lesson:
- `02-beginner-drills.md`
- `03-grammar-drills.md`
- etc.

### 2. Unit quizzes
Test knowledge after completing each module:
- `unit-quiz-02-beginner.md`
- `unit-quiz-03-grammar.md`
- etc.

### 3. Checkpoint tests
Comprehensive tests at major milestones

---

## How to use exercises

1. **After learning:** Do drills immediately
2. **Next day:** Review drill results
3. **End of module:** Take unit quiz
4. **Milestone:** Take checkpoint test
