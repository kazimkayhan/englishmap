# Answer Keys Guide

**Learning goal:** Use answer keys effectively for self-study

---

## How to use answer keys properly

### ✅ DO:
- Complete exercise FIRST
- Check answers AFTER finishing
- Review mistakes carefully
- Note patterns in errors
- Redo incorrect items

### ❌ DON'T:
- Look while doing exercise
- Just check final score without reviewing
- Feel shame about mistakes
- Skip redoing wrong answers

## Learning from mistakes

When you get something wrong:
1. Read the correct answer
2. Understand WHY it's correct
3. Find the rule/pattern
4. Create 2 similar examples
5. Review in 3 days

---

## Честит код (Honesty code)

Self-study requires honesty. Only you know if you checked answers first. Be honest with yourself — it's the fastest path to learning.
