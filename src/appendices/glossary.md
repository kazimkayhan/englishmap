# Glossary of Study Terms

| Term | Meaning |
|------|---------|
| **A1–A2** | Beginner CEFR levels |
| **B1–B2** | Intermediate CEFR levels |
| **C1–C2** | Advanced CEFR levels |
| **CEFR** | Common European Framework — global level scale |
| **Checkpoint** | End-of-stage test (see [14-assessments.md](14-assessments.md)) |
| **Dictation** | Write what you hear |
| **Fluency** | Smooth, understandable speech (not perfection) |
| **Graded reading** | Text at your level (~80% known words) |
| **Hedging** | Soft language: *may*, *seem*, *tend to* |
| **L1** | Your first language (Dari) |
| **Minimal pair** | Two words differing by one sound (*ship/sheep*) |
| **Placement quiz** | Test to find starting module |
| **Register** | Formal vs informal style |
| **Relative clause** | Clause with *who/which/that* |
| **Rubrics** | Self-scoring guide for speaking/writing |
| **Shadowing** | Repeat audio immediately after speaker |
| **Spaced repetition** | Review at increasing intervals |
| **SVO** | Subject – Verb – Object word order |
| **Scanning** | Fast search for dates, names, numbers |
| **Self-talk** | Describe your day aloud in English |
| **Stage 0–4** | This roadmap’s five learning stages |
| **Subtitle weaning** | Moving from English subs to no subs |
| **Survival English** | Hello, thanks, help, numbers |
| **Thematic vocabulary** | Words grouped by topic (health, study) |
| **Tracker** | Weekly log in [16-tracker.md](16-tracker.md) |
