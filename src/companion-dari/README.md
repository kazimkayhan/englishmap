# راهنمای همراه دری (Dari Companion)

**این فایل‌ها ترجمهٔ کامل درس نیستند.** خلاصهٔ ماژول‌های انگلیسی به **دری** تا بفهمید چه می‌خوانید — سپس تمرین را به **انگلیسی** ادامه دهید.

---

## چگونه استفاده کنیم

1. ماژول انگلیسی را باز کنید (مثلاً `03-core-grammar.md`).
2. خلاصهٔ دری همان بخش را بخوانید.
3. تمرین و جملات را **به انگلیسی** بنویسید و بلند بخوانید.
4. کلید پاسخ را فقط بعد از تلاش ببینید.
