# Checkpoint Tests

**Learning goal:** Measure overall progress at key milestones

---

## Checkpoint schedule

**Week 12:** Beginner checkpoint (A1-A2)  
**Week 24:** Intermediate checkpoint (B1)  
**Week 39:** Upper intermediate checkpoint (B2)  
**Week 52:** Advanced checkpoint (B2+/C1)

---

## Checkpoint components

1. **Grammar** (20 questions)
2. **Vocabulary** (30 questions)
3. **Listening** (1 clip, 10 questions)
4. **Reading** (1 passage, 10 questions)
5. **Writing** (100-200 words)
6. **Speaking** (2-3 min recording)

---

## Passing criteria

70%+ on each section to move forward confidently

Below 70%? Review that skill area for 2 more weeks.
