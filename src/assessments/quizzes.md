# Unit Quizzes

**Learning goal:** Test knowledge after each module

---

## Quiz locations

Each module has an associated quiz in `exercises/` folder:
- [Unit Quiz 02 - Beginner](../exercises/unit-quiz-02-beginner.md)
- [Unit Quiz 03 - Grammar](../exercises/unit-quiz-03-grammar.md)
- And so on...

---

## How to use quizzes

1. Complete the module first
2. Take quiz WITHOUT looking at notes
3. Check answers in [Answer Keys](../answer-keys/)
4. Review topics you missed
5. Retake after 1 week if score < 70%
